# Public tool library

This repository is the public adoption surface for The Atomiton. Publish only tools with a usable verified free path for the listed function. Payment-required tools do not qualify. Keep optional paid features outside the entry's listed capability.

Tools may be existing third-party tools, original builds, or adaptations discovered through research. Preserve their original source, licence, actual usage evidence, version and attribution. Distinguish third-party claims, Atomiton tests, synthetic checks, field trials and observed benefit.

Keep candidates, unverified conclusions and personal case records outside public-ready claims. A tool count, test pass or single corrected result cannot establish wider MAYHEM conformance, a completed investigation, sustained White capability or the Red threshold.

Source data is catalogue.json, web/, tools/ and evidence/. Run python scripts/build.py, python scripts/check.py and node --test tests/catalogue.test.cjs. Commit the generated docs/ output. Never put credentials, control-runtime state or private source documents in this repository.
